# Q & T Foods ERP + CRM

The repository contains the Laravel backend in [`BackEnd`](BackEnd/README.md) and the React frontend in [`FrontEnd`](FrontEnd/README.md).

P0, P1, P2, and all three P3 slices are implemented through the complete master-data, inventory, procure-to-pay, manufacturing, order-to-cash, dispatch, claims, receivables, core/supplement finance, inter-plant transfer, consolidation, exact-tenant portal, private document-exchange, and governed optimisation workflows. See [`ERP_IMPLEMENTATION_GAPS.md`](ERP_IMPLEMENTATION_GAPS.md) for the verified test baseline and the two remaining reporting/help prototype screens.
